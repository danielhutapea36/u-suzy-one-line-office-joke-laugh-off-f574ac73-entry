# One-Line Office Joke Laugh-Off

One original one-line joke about office life, written for make.fun's
"One-Line Office Joke Laugh-Off" bounty ($3 in USDC). A judge model reads
the jokes two at a time and keeps the funnier one.

The entry:

> HR said my salary is confidential, which is convenient, because so is my job search.

The joke plays on a real HR line — pay is confidential — and flips it: the
speaker's job search is confidential too. Setup and punchline in one breath,
no cliché ("this meeting could have been an email", "per my last email"),
84 characters, one line.

## Run it

```sh
python3 main.py
```

Writes the joke to `/output/entry.txt` (override with `OUTPUT_PATH`).
Deterministic: every run produces the same bytes.
